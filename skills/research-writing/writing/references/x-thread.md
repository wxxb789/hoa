# X posts and threads (2026-11-21)

- Put the observation or claim early. For a thread, make each post useful on its own and let
  the sequence build the argument. Use a single post when the evidence fits comfortably.
- Cite the source or show a useful fragment close to the claim. Use media when it makes the
  comparison or result easier to inspect; provide a useful description.
- Check the current composer, account and service limits before finalizing. Preserve the
  conclusion and its caveat when shortening; do not make a follow-up carry all the context.
- End where the point is complete. A link or question is useful only when it gives the reader
  a way to verify, act, or respond.
