# Report workflow (2026-11-21)

## Citation ledger

Start a fresh ledger for an independent draft; keep existing IDs for a continuation.
Register sources before citing them, put each marker next to the supported claim, and
render the source list mechanically. After edits, reconcile every ID and its title/topic
with the actual claim, remove stale entries, rerender, and run strict ledger verification.

## Negative findings and backfill

- For a date-bounded search, reject results outside the window even when the query
  specified it. Keep a trace of a leaky search round and rerun it before using the results.
- Log each plausible but excluded result with its disqualifying reason. Do not fill a
  defined population's gap with adjacent populations or theoretical examples.
- Add a dated batch to frozen evidence; do not edit the existing packet or report.
  Retrieve and quote the original full text for each rechecked item. Credit the original
  publisher, not the reprint. A catalog or DOI record proves existence only.
  Record which claims changed and whether the delivered report needs revision.

## Parallel draft rounds

Reuse the frozen evidence packet. Keep each draft and receipt, and encode the
iteration, outline, style, and writer in its filename. Record their version map in
the draft directory. When the brief specifies a matrix, fill all missing combinations.
Advance each combination only on operator comments. Only the operator promotes a new
final version; keep the prior approved final byte-identical.
