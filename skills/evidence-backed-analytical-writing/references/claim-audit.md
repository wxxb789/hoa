# Claim audit: status-aware wording

| Claim class | Safe wording | Do not write without evidence |
|---|---|---|
| Fielded inventory | “公开资料显示已列装/已部署……” with date and scope | “现有总数为……” when the denominator is unclear |
| Procurement or program target | “提出指标/计划采购/目标是……” | “已经形成能力/已经列装……” |
| Prototype or demonstration | “在某次演示/试验中验证……” | Generalizing one demo into routine operational performance |
| Type/model count | “公开列出的型号/项目包括……” | Adding type counts from incompatible lists or years |
| Performance metric | Include unit, test conditions, duration, and mode | A bare range, payload, or endurance figure |
| Historical trend | Give both endpoints and the interval | Treating historical growth as current inventory |
| Analytical inference | “这表明/可推断/意味着……” | Presenting the inference as a source-reported fact |
| Unsupported supplied statistic | “未找到可核验的同口径来源，改用……” | Repeating a precise percentage or total because it appeared in the brief |

## Minimum evidence map

Before drafting, make a compact internal table with:

`claim | source URL/id | exact figure or wording | date | denominator/scope | status | safe sentence`

If two claims use different years, populations, or status categories, keep them
separate unless a source explicitly makes the comparison. If the source is a plan,
label it as a plan; if it is a demonstration, label it as a demonstration.

## Evidence-status ladder

Rank every load-bearing claim on this ladder and never let one tier's evidence carry the
next tier's conclusion:

| Tier | Evidence that establishes it | Safe wording |
|---|---|---|
| 需求/概念 | planning documents, solicitations | “提出设想/立项研究……” |
| 合同 | award notices, contract records | “已授出合同/进入采办……” |
| 试验/演示 | exercise reports, demo records | “在某次试验/演示中……” |
| 交付/列装 | official fielding/delivery records | “已交付/已列装……” |
| 有限使用 | dated operational records | “已在某任务中使用……” |
| 独立测量结果 | independent audit/study with baselines | “经独立评估，指标为……” |

- A contract award does not prove fielding; a demo does not prove sustained use; an official
  self-report does not prove a measured outcome.
- When merging a second evidence stream, preserve each claim's original tier — appearing in two
  streams does not promote it.
- State the tier ceiling explicitly when a source is ambiguous, and keep future dates labeled as
  plans, not events.
