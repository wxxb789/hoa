# X / Twitter

For single posts and threads. X = a place for thinking-out-loud + sharp takes (dbskill: 推文 =
个人思考的记录与集合).

## Single post
- ≤280 chars. **Hook in the first line** — it's all most people see.
- One claim per post. End on the point, not a question (unless genuinely soliciting replies).
- 0–2 hashtags max, and only if they're real communities. No hashtag soup.
- A concrete number / screenshot / one-liner beats an adjective.

## Thread
- **Post 1 = the whole thesis** in tweetable form + a reason to keep reading. Add 🧵 if you like.
- Each following post = ONE self-contained beat (a step, a point, an example). It should make
  sense even if quoted alone.
- Number posts (1/, 2/ …) when >4. Last post = takeaway or link/CTA (soft).
- Don't stretch one idea across 10 posts. If it's one idea, it's one post.

## Hook patterns (from dbskill: 话题 + Hook + 可信度, leave 悬念)
- Lead with a result + credibility: "Shipped X. Cut p99 from 800ms→90ms. Here's the one change."
- Tension/curiosity, don't pre-give the answer: "Everyone says X. After Y, I think the opposite."
- Specifics create credibility: numbers, before/after, a named tool, a real screenshot.

## Tone
- Punchy, declarative, concrete. Plain words. It's a thought log, not a press release.
- Opinions welcome; back them with a reason or example in the same post.

## Don'ts
- No "a thread 👇🔥🔥", no engagement-bait ("RT if you agree", "comment 'X' and I'll DM you").
- No hashtag soup, no @-spam, no thread that's filler stretched for reach.
- Don't fabricate metrics or screenshots.

## AI-smell to watch
- Uniform sentence rhythm matters less here (posts are short) — but still avoid the
  "钩子+痛点+承诺" anxiety-selling opener and the every-line-is-a-quote cadence.

## Quick checklist
- [ ] First line hooks; one claim per post
- [ ] Thread post 1 carries the whole thesis
- [ ] Real specifics (numbers/screenshot), no bait, ≤2 real hashtags
