# Style benchmarking (2026-11-21)

Compare the author's draft with public work written for a comparable audience and purpose.
Prefer representative original posts over book excerpts or pages heavily edited for a
different format. Sample different subjects and formats; record why each sample qualifies.

Extract the body, excluding navigation and repeated templates. Check for truncation and
do not count missing material as a style choice. Run the same measurement for samples and
the current draft: `uv run scripts/style_stats.py <dir> [prefix]` and
`uv run scripts/first_last.py <dir> [prefix]` help locate differences in rhythm, density, and
openings/closings. Put the comparison drafts in a separate directory or select them by prefix.

Read representative passages and explain what the difference does for the reader. A high
number density can be useful parameters or irrelevant output counts; the count alone cannot
distinguish them. Recommend editorial changes with an example purpose, not borrowed wording,
signature expressions, universal quotas, or imitation of a named person's voice. Apply changes
only when authorized; update the owning channel or project contract and verify a new draft
against the same comparison.
