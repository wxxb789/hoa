# pulse — Converged Specification

## Problem

Build `pulse` (CLI `pulse`, background daemon `pulsed`), a fast local script runner in this brand-new repository. No Core Design document or goal folder exists yet.

## Scope & Non-Negotiable Invariants

- **INV-CLIENT-AOT**: `pulse` is compiled as a native thin client (`PublishAot=true`) talking to `pulsed` over private local IPC; never spawn intermediate runtime wrapper processes on the hot path.
- **INV-MEM-EMIT**: `pulsed` evaluates scripts purely in memory with zero temporary `.dll` writes to disk.
- **Workstreams**:
  - **S1** (end-to-end thin client + warm daemon vertical slice): ready now; fits within one 12-hour feedback window; no open user questions.
  - **S2** (background-replenished session pool & stream isolation): depends on `S1`; ready after `S1`; fits within one feedback window; no open user questions.
  - **S3** (external security sign-off): the corporate security team—not the agent or repo owner—reviews the `S2` audit packet next month and files signed clearance `SEC-09` before public distribution.
  - **S4** (plugin marketplace distribution): depends on `SEC-09`; unresolved owner choice on whether third-party plugins run in-process or out-of-process (`Q-SANDBOX`), to be decided after `S2` measurements.

## Out of scope

- Public HTTP listeners or remote network servers (`NON-HTTP`).

## Acceptance

- Benchmark gate on `S1`/`S2`: warm `pulse` achieves `>= 20x` median speedup over stock runner via `./bench/run-interleaved.sh`.
