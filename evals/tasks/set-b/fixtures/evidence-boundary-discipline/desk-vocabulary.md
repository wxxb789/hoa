# Knowledge desk formatting card

Use dates as YYYY-MM-DD. Machine worksheet vocabulary:

| Field | Terms |
|---|---|
| Announcement status | planned; issued; withdrawn |
| Current charter status | issued; unpublished; withdrawn; unknown |
| Search result | located; not located; not searched |
| Evidence labels | fact; report; judgment; unknown; carried citation; not rechecked; reread |

Use all applicable labels for each surface. Citation locators use the source's
printed notation (for example, paragraph 2). The page is read separately from
the delivery sheet and query page.
