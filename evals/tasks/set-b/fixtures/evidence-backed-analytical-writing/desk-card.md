# Worksheet codes

Sorting statuses: contract ceiling; demonstration throughput; delivered units;
in service; project target; undetermined.

Night-shift outcome: qualifying case located; no qualifying case located.
Use one exclusion per look-alike: wrong operator; simulation only;
bibliography only; outside window; wrong shift; no independent measurement.
The upkeep index records are housekeeping, not candidate studies.

Coverage denominator: the population eligible to deploy the tagged-crate
workflow, not all sites the network owns.
