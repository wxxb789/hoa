# Harbor records panel: current docket notice

Application packets for collection BR-41 can be lodged in the intake sandbox
with the approved dossier, rights matrix, and delegation letter already in
the archive team's packet bundle. Staff can assemble and validate the dossier
from those inputs in one afternoon; no additional owner input is required.
Running packet-lint on the bundle and obtaining a registry receipt for case
BR-41 is the archive owner's agreed handoff evidence. Sandbox filing does not
distribute collection material or grant a license.

Only the panel issues a redistribution license. It votes next month, then
files the signed resolution against BR-41 in its decision register. An intake
receipt, a completeness email, and an agenda listing are not a decision.
