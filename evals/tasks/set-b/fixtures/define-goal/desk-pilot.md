# Staff lookup: November pilot

The desk can run an internal pilot using inventory INV and the sample queries
in the existing desk test pack. Success means desk staff can find the right
inventory record and see the applicable access category for each test-pack
query, without exposing restricted recordings. The owner will review the
demonstration after the agent returns. A prototype from last month used
thumbnails; those are not required. Desk work fits in one afternoon and does
not use the registry or require permission to distribute recordings.

The public edition is a separate export from the inventory, not from the
desk tool. It needs a granted redistribution license. Its disclosure scope is
not fixed in the desk test pack.
