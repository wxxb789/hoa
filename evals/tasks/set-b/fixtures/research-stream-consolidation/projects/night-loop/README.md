# Night Loop

The consolidated collection lives under this project. Incoming streams use
`streams/<stream-id>/`; keep their internal layout so replay paths remain
usable. The project collection is canonical when an incoming source export
matches one already here. Attempt outputs and errors are retained as run
evidence, including no-output attempts. See [the Delta capture](../../staging/delta/capture.json)
and [the study register](../../control/registry.json).

The briefing uses `claim` for direct, independently locatable evidence,
`summary` for attributed but non-locatable observations, and `omit` for items
with no defensible publishable figure or wording.
